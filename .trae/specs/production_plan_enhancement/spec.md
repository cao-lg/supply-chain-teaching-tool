# 生产计划手动编辑与影响分析规格文档

## Why
当前生产计划模块存在以下问题：
1. 计划只能通过订单生成，不支持手动创建和编辑
2. 修改数量后无法直观看到资源消耗影响
3. 缺少工时、设备产能消耗的可视化分析

## What Changes
- 支持手动创建生产计划（不依赖订单）
- 支持在计划表中直接编辑数量
- 添加实时影响分析面板
- 显示工时消耗、设备产能消耗、物料消耗

## Impact
- Affected specs: sample_data_design
- Affected code: js/modules/productionPlan.js

## ADDED Requirements

### Requirement: 手动创建生产计划
用户应能手动创建生产计划，无需依赖订单。

#### Scenario: 手动创建计划
- **WHEN** 用户点击"添加生产计划"
- **THEN** 系统应显示创建表单，包含产品、数量、日期等字段
- **AND** 自动计算所需工时和设备资源

### Requirement: 计划表内编辑
用户应能在计划表中直接编辑数量。

#### Scenario: 编辑数量
- **WHEN** 用户在计划表中点击数量字段
- **THEN** 系统应允许内联编辑
- **AND** 实时更新影响分析

### Requirement: 影响分析面板
系统应实时显示计划变更的影响。

#### Scenario: 显示影响分析
- **WHEN** 用户创建或编辑生产计划
- **THEN** 系统应显示：
  - 总工时消耗（人时）
  - 设备产能消耗（设备日产能百分比）
  - 物料消耗清单
  - 产能缺口预警

### Requirement: 资源冲突检测
系统应检测资源冲突并给出预警。

#### Scenario: 产能冲突
- **WHEN** 计划数量超过设备日产能
- **THEN** 系统应显示红色预警

#### Scenario: 工时冲突
- **WHEN** 所需工时超过工人可用工时
- **THEN** 系统应显示黄色预警

## 影响分析计算逻辑

### 工时计算
```
总工时 = Σ(产品数量 × 产品单位工时)
示例：智能手表 100个 × 0.5工时/个 = 50工时
```

### 设备产能计算
```
设备产能消耗率 = 计划数量 / 设备日产能 × 100%
示例：100个 / 80个/天 = 125%（超载）
```

### 物料消耗计算
```
物料消耗 = Σ(产品数量 × BOM物料数量)
示例：智能手表 100个 × 锂电池1个 = 100个锂电池
```

# 生产计划总表与编辑功能规格文档

## Why
当前生产计划模块存在以下问题：
1. 没有独立的生产计划总表视图
2. 无法手动添加生产计划
3. 生产计划列表中数量不可编辑
4. 缺少资源消耗影响分析

## What Changes
- 添加"生产计划总表"标签页
- 添加手动创建生产计划功能
- 支持内联编辑数量
- 添加实时影响分析面板

## Impact
- Affected specs: production_plan_enhancement
- Affected code: js/modules/productionPlan.js

## ADDED Requirements

### Requirement: 生产计划总表视图
系统应提供独立的生产计划总表视图。

#### Scenario: 查看生产计划总表
- **WHEN** 用户点击"生产计划"模块
- **THEN** 系统应显示"生产计划总表"标签页
- **AND** 显示所有生产计划的汇总信息

### Requirement: 手动添加生产计划
用户应能手动创建生产计划。

#### Scenario: 手动创建计划
- **WHEN** 用户点击"添加生产计划"按钮
- **THEN** 系统应显示创建表单
- **AND** 包含产品、数量、日期、设备、工人等字段

### Requirement: 数量内联编辑
用户应能在计划表中直接编辑数量。

#### Scenario: 编辑数量
- **WHEN** 用户点击数量单元格
- **THEN** 系统应允许内联编辑
- **AND** 实时更新影响分析

### Requirement: 影响分析面板
系统应实时显示资源消耗分析。

#### Scenario: 显示影响分析
- **WHEN** 用户查看或编辑生产计划
- **THEN** 系统应显示：
  - 总工时消耗
  - 设备产能消耗率
  - 物料消耗清单
  - 库存充足性检查

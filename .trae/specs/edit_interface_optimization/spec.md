# 编辑界面优化规格文档

## Why
当前编辑界面存在以下问题：
1. 界面过于松散，空间利用率低
2. 视觉设计不够美观，缺乏现代感
3. 不同模块的编辑界面风格不一致
4. 表单元素排列不够紧凑，用户体验不佳

## What Changes
- 统一所有编辑模态框的设计风格
- 优化表单布局，提高空间利用率
- 增强视觉层次感和美观性
- 统一按钮样式和位置
- 优化表单验证反馈

## Impact
- Affected specs: 所有包含编辑功能的模块
- Affected code: 
  - js/modules/basicData.js
  - js/modules/productionPlan.js
  - js/modules/purchasePlan.js
  - js/modules/inventory.js
  - js/modules/productionCapacity.js
  - js/modules/logistics.js
  - js/modules/customerService.js

## ADDED Requirements

### Requirement: 统一编辑界面设计
所有编辑模态框应采用统一的设计风格。

#### Scenario: 打开任意编辑模态框
- **WHEN** 用户打开编辑模态框
- **THEN** 模态框应具有统一的样式和布局
- **AND** 表单元素排列紧凑且美观

### Requirement: 优化表单布局
表单元素应采用紧凑布局，提高空间利用率。

#### Scenario: 填写表单
- **WHEN** 用户填写表单
- **THEN** 表单元素应排列紧凑
- **AND** 标签和输入框对齐整齐

### Requirement: 增强视觉设计
编辑界面应具有现代感和视觉层次感。

#### Scenario: 查看编辑界面
- **WHEN** 用户查看编辑界面
- **THEN** 界面应具有清晰的视觉层次
- **AND** 颜色搭配协调

### 设计规范
1. **模态框大小**：根据内容自适应，最大宽度限制
2. **表单布局**：
   - 标签右对齐，输入框左对齐
   - 标签宽度统一（100px）
   - 输入框宽度统一（300px）
   - 行高：36px
   - 间距：12px
3. **颜色方案**：
   - 主色调：#0d6efd（Bootstrap primary）
   - 边框：#dee2e6
   - 背景：#ffffff
   - 提示文本：#6c757d
4. **按钮样式**：
   - 取消按钮：outline-secondary
   - 保存按钮：primary
   - 按钮大小：sm
   - 按钮间距：8px
5. **验证反馈**：
   - 错误状态：红色边框 + 错误提示
   - 成功状态：绿色边框
   - 提示文本：12px

### 优化前后对比

**优化前：**
- 松散的垂直布局
- 大间距
- 视觉层次不清晰
- 按钮位置不统一

**优化后：**
- 紧凑的网格布局
- 合理间距
- 清晰的视觉层次
- 统一的按钮位置
- 现代美观的设计
